Changelog

User-visible changes to Web Bio Tools, most recent first.

2026-09-15
  • Added the All-by-all alignment matrix page, for comparing many sequences at once.
  • Added FASTA file upload to the all-by-all page.
  • The all-by-all matrix now shows a different metric above and below the diagonal.
  • Added a Markdown report download for all-by-all results.
2026-06-12
  • Added a "Flip query" toggle to the delta file dot plot.
2026-04-07
  • The DNA to protein translator now supports URL-controlled translation presets, for linking directly to a specific translation.
2026-03-16 – 2026-03-17
  • Added the Delta file viewer, for displaying nucmer/promer dot plots.
  • Added a circular rotation control to the dot plot.
  • Added a "Download SVG" button to the delta file viewer.
  • Added an adjustable plot size slider to the delta file viewer.
  • Alignment lines in the dot plot now show tooltips with original genomic coordinates.
  • Added more information about the project to the front page.
2026-01-27
  • Improved FASTA headers in downloaded output.
2025-11-11 – 2025-11-28
  • Added the HMM viewer page, for exploring HMMER3 profiles, including a sequence logo visualization with a toggleable color legend.
  • Added the DNA to protein translator (fna2faa) page, with six-frame translation, FASTA-formatted output, an example loader, and a FASTA download option.
  • The sidebar navigation is now shared consistently across all pages.
2025-07-01 – 2025-07-16
  • Initial release: browser-based pairwise sequence alignment (Smith-Waterman and Needleman-Wunsch), running entirely client-side via WebAssembly.
  • Added BLOSUM62 and custom scoring matrices, with adjustable affine gap penalties.
  • Alignment results can be saved to your browser's local storage, shared via URL, and downloaded.
  • Added the FAQ page.
